# Golf Alley — Roll It Smooth

A mobile-first browser putting game. **The Founders Nine** is the initial playable nine-hole course.

## Play

The game is a static website in [`index.html`](./index.html). On a phone or desktop browser, drag back on the green to aim and set shot power, then release to putt. Score all nine holes and try to beat your best round.

Current prototype:
- Nine playable holes with different layouts
- Touch and mouse putting controls
- Arcade ball physics, rebounds, obstacles, slopes and sand hazards
- Per-hole strokes, a scorecard, and locally saved personal best
- No account or external dependencies required

## Publish with GitHub Pages

1. Open **[Repository Settings → Pages](https://github.com/golfiqdaily72/Golf-alley/settings/pages)**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then press **Save**.
4. After GitHub reports a successful deployment, open **https://golfiqdaily72.github.io/Golf-alley/**.

GitHub Pages is not automatically enabled by committing code. Hosting becomes public when GitHub Pages is enabled and deployed.

## Planned development

This is a **2.5D prototype** to validate controls and game feel, not a finished 3D production game. Future work includes improved shot physics and mobile UX, an additional free nine-hole course, challenges, unlockable content, and eventually iOS/Android packaging.

Source of truth: the `main` branch of this repository.
